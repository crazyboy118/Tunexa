# 🎵 Tunexa

**Tunexa** is a sleek, lightweight, and responsive music streaming web application inspired by Spotify. Built using core web technologies, it provides a smooth audio playback experience, dynamic song navigation, and a modern dark-themed user interface.

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E)

---

## Features

- **Custom Audio Player:** Fully functional play, pause, next/previous track controls, and an interactive seek bar powered by the HTML5 Audio API.
- **Dynamic Library/Search:** Easily browse through songs, artists, or albums with responsive layout design.
- **Modern UI/UX:** A clean, Spotify-inspired dark aesthetic featuring flexible CSS layouts (Flexbox/Grid) for great responsiveness across screens.
- **Client-Side Interactivity:** Smooth state transitions, active track highlighting, and custom controls built entirely with vanilla JavaScript.

---

## Built With

- **HTML5** – For structured content and the underlying audio element.
- **CSS3** – For styling, layouts, custom variables, and responsive design.
- **JavaScript (ES6+)** – For audio state management, DOM manipulation, and app interactivity.
